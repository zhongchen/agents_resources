# agents_resources

Zhong's personal knowledge bank for AI coding agents. Any agent, on any
model, reads `INDEX.md` for a one-line-per-entry summary and opens relevant
entries under `entries/` on demand. Public on GitHub, but personal, not a
community project.

Start here:

- `AGENTS.md` — what agents should read and how they contribute
- `CONTRIBUTING.md` — entry template and topic list
- `INDEX.md` — auto-generated index of everything in the bank
